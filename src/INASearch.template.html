Define Block/Module categories

Edit the structure below inside INASearch. Applying it creates the configured empty module notes and includes the structure in the next autosave.

{
  "blocks": [
    {
      "id": "block-1",
      "number": 1,
      "title": "Your block title",
      "modules": [
        { "id": "module-1", "number": 1, "title": "Your module title" }
      ]
    }
  ]
}

Enter only the object inside courseStructure, beginning with { and ending with }. Block IDs must be unique; module IDs must be unique within their block. Keep IDs stable after assigning notes because notes link to those IDs. Put controlled titles only in the authorized environment.

Important boundaries

        
The Definitions catalog preserves USCIS Glossary explanations and explicit “the term” definitions throughout the included INA, along with 8 CFR 1.2, as separate source records. Glossary entries are categorized as USCIS Policy; statutory and regulatory entries are categorized as Law. Applicability labels retain the governing source scope, and INASearch does not merge competing definitions or infer a universal meaning.

        
In the standard build, official House cross-references whose targets are included in Title 8 are rendered as local links. References outside the included Title 8 material remain plain text rather than being assigned an unverified local target.

        
INASearch is an open-book study aid, not legal advice and not a substitute for checking the current official source. This build includes dated offline U.S. Code and CFR snapshots; current-source actions remain available.

        
INA citations and U.S.C. citations are preserved as distinct citation systems. A crosswalk is shown only when the USCIS INA table directly supplies it. Named-Act results are references found in approved sources—not complete reproductions of those Acts.

        
Immigration card fields are unlocked by identifying their approved source in six-choice, open-resource questions. A wrong resource answer locks only that specific question for one minute and keeps it open so its linked sources can still be reviewed; selected answers are not retained. The older status and fact questions remain available as optional practice without a retry timeout and do not control card content. Until autosaving is enabled, completed resource checks, resource-question lockouts, and practice progress remain only in the current browser tab.
