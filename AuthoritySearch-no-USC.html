Define Block/Module categories

Edit the structure below inside AuthoritySearch. Applying it creates the configured empty module notes and includes the structure in the next autosave.

{
  "blocks": [
    {
      "id": "block-1",
      "number": 1,
      "title": "Your block title",
      "modules": [
        { "id": "module-1", "number": 1, "title": "Your module title" }
      ]
    }
  ]
}

Enter only the object inside courseStructure, beginning with { and ending with }. Block IDs must be unique; module IDs must be unique within their block. Keep IDs stable after assigning notes because notes link to those IDs. Put controlled titles only in the authorized environment.

Inspect the embedded corpus

The corpus is compact JSON compressed with standard gzip and represented in the HTML with standard Base64. Base64 is transport encoding—not encryption or obfuscation. Decompression happens only in memory and requests no browser permission.

  1. Extract the text inside the authoritySearchCorpusData element.
  2. Base64-decode it to AuthoritySearch-Corpus.json.gz.
  3. Decompress it with an ordinary gzip-compatible tool.
  4. Compare the resulting byte counts and SHA-256 hashes with the manifest above.
  5. Open the decompressed UTF-8 JSON in a text editor.

Important boundaries

        
The Definitions catalog preserves USCIS Glossary explanations and explicit definitions from INA 101 and 8 CFR 1.2 as separate source records. Glossary entries are categorized as USCIS Policy; statutory and regulatory entries are categorized as Law. Applicability labels retain the governing source scope, and AuthoritySearch does not merge competing definitions or infer a universal meaning.

        
In the standard build, official House cross-references whose targets are inside cached Title 8 are rendered as local links. References outside the cached Title 8 corpus remain plain text rather than being assigned an unverified local target.

        
AuthoritySearch is an open-book study aid, not legal advice and not a substitute for checking the current official source. U.S. Code handling depends on this build; regulation links open on current eCFR.

        
INA citations and U.S.C. citations are preserved as distinct citation systems. A crosswalk is shown only when the USCIS INA table directly supplies it. Named-Act results are references found in approved sources—not complete reproductions of those Acts.

        
Immigration card fields are unlocked by identifying their approved source in six-choice, open-resource questions. A wrong resource answer locks only that specific question for 30 minutes; other questions remain available and selected answers are not retained. The older status and fact questions remain available as optional practice without a retry timeout and do not control card content. Until autosaving is enabled, completed resource checks, resource-question lockouts, and practice progress remain only in the current browser tab.
