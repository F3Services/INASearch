How to define Block/Module categories

Close AuthoritySearch, open AuthoritySearch-Profile.js in a text editor, and replace the empty courseStructure object with this pattern. Save the file, then reopen AuthoritySearch.html.

"courseStructure": {
  "blocks": [
    {
      "id": "block-1",
      "number": 1,
      "title": "Your block title",
      "modules": [
        { "id": "module-1", "number": 1, "title": "Your module title" }
      ]
    }
  ]
}

Copy a complete block or module object to add another. Block IDs must be unique; module IDs must be unique within their block. Keep IDs stable after assigning notes because notes link to those IDs. Use positive whole numbers for display order. Titles may be blank. Preserve quotation marks and commas. Put controlled titles only in the profile on the authorized network.

Coverage, capture dates, provenance rules, and operational limits.

Important boundaries

AuthoritySearch is an open-book study aid, not legal advice and not a substitute for checking the current official source. The local U.S. Code is a captured edition; only short regulatory excerpts supporting card facts are cached, while regulation links open on current eCFR.

INA citations and U.S.C. citations are preserved as distinct citation systems. A crosswalk is shown only when the USCIS INA table directly supplies it. Named-Act results are references found in approved sources—not complete reproductions of those Acts.

Visa summaries and facts are revealed through multiple-choice study checks. A wrong answer retains only the affected question and retry-until time; the selected answer and attempt history are not retained. Notes remain in memory unless a profile file is connected or a replacement profile is downloaded.
